# 图片加层（碎屏效果）

一个单文件 HTML 小工具：给图片叠加一层"碎屏"效果并导出 PNG。全程本地运行，不需要联网。

## 使用方法

1. 双击打开 `图片加层.html`（建议 Chrome / Edge）。
2. 点"选择文件"加载一张图片，页面会实时显示叠加效果。
3. 不满意破损的位置/形状，点 **随机破损** 重新生成。
4. 点 **下载 PNG** 保存结果，下载的就是预览看到的样子。

## 叠加层的内容

从上到下依次是（除以下元素外全透明，直接 100% 叠在原图上）：

- **纯黑竖线**：水平居中，从图片顶部到破损中心。
- **纯黑破损块**：不规则多边形，限制在一个竖椭圆范围内（宽约为图片宽 4%，高约 14%）。
- **纯紫亮线**（`#a020f0`）：从破损块底部沿竖直方向到图片底部，带同色发光。
- **纯绿亮线**（`#00ff00`）：从破损块中心水平向右到图片右边缘，带同色发光。

亮线先画、黑色后画，所以亮线正好从破损边缘接出来，不会压到黑色上。

## 参数位置

都在 `图片加层.html` 里的 `makeDamage()` 函数中，按需改数字：

| 想改什么 | 改哪里 |
|---|---|
| 破损位置 | `Xc`（水平，默认 0.5）和 `Yj`（竖线终点，默认 0.6），位置固定，不参与随机 |
| 破损块大小 | `rx` / `ry`（椭圆半径） |
| 线条粗细 | `drawOverlay()` 里的 `0.004`（黑线）和 `0.003`（亮线），按图片宽度比例 |
| 颜色 | `drawOverlay()` 里的 `#a020f0` 和 `#00ff00` |

## 说明

- 图片只在本页面内处理，不会上传到任何地方。
- "随机破损"只随机破损块的形状；破损位置始终固定（水平居中、竖线终点在距底部 40% 处）。
