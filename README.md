# 图片加层（碎屏效果）

一个单文件 HTML 小工具：给图片叠加一层"碎屏"效果并导出 PNG。全程本地运行，不需要联网。

## 使用方法

- 即刻体验：<https://knvbepr.github.io/DuoBreakWallpaper/>

1. 双击打开 `index.html`（Chrome / Edge / Firefox 均可）。
2. 点"选择文件"加载一张图片，页面会实时显示叠加效果。
3. 不满意破损的形状，点 **随机破损** 重新生成（只随机形状，位置固定）。
4. 可用色盘单独改两条亮线的颜色，用滑杆调右边亮线的宽度；页面上的 **缩放** 按钮在 适应高度 / 适应宽度 / 1:1 之间轮换（只影响预览，不影响导出）。
5. 点 **下载 PNG** 保存结果，导出的是原分辨率的合成图。

## 叠加层的内容

效果直接画在原图上，导出的是合成后的整张图片：

- **纯黑竖线**：水平居中，从图片顶部到破损中心。
- **纯黑破损块**：不规则多边形，限制在竖椭圆范围内（宽约为图片宽的 4%，高约 14%）。
- **下面亮线**（竖，默认紫 `#a020f0`，页面色盘可改）：从破损块中心竖直向下到图片底部，纯色实线，无光晕。
- **右边亮线**（横，默认绿 `#00ff00`，页面色盘可改）：从破损块内部水平向右到图片右边缘，纯色实线，无光晕；粗细用滑杆调（基准线宽的 1~8 倍）。

开启 **随机横线** 后，会在主线上下的空隙里再加 1~3 条细线：粗细为 1 像素 ~ 1.5 倍基准线宽（不随滑杆放大），与主线至少隔 8px，不会连成一整片。

所有亮线的起点都藏在破损块内部、线端用平头，所以线不会从破损边缘外露；亮线先画、黑色后画，亮线正好从破损边缘接出来，不会盖住黑色。

## 参数位置

都在 `index.html` 里，按需改数字：

| 想改什么 | 改哪里 |
|---|---|
| 破损位置 | `makeDamage()` 里的 `Xc`（水平，默认 0.5）和 `Yj`（竖线终点，默认 0.6），位置固定，不参与随机 |
| 破损块大小 | `makeDamage()` 里的 `rx` / `ry`（椭圆半径） |
| 线条粗细 | `drawOverlay()` 里的 `0.004`（黑线）和 `0.003`（亮线），按图片宽度比例 |
| 颜色 | 页面色盘（默认值在 HTML 的 `<input type="color">` 的 `value` 里） |
| 随机横线 | `makeGLines()`：条数（1~3）、粗细上限、与主线的间距 |

## 说明

- 图片只在本页面内处理，不会上传到任何地方。
- "随机破损"只随机破损块的形状；破损位置始终固定（水平居中、竖线终点在距底部 40% 处）。
- 预览缩放只影响显示，导出的 PNG 始终是图片原始分辨率。
